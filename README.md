# Hórus Hub — atualizações

Este repositório guarda só as versões do Hórus Hub (os arquivos `HorusHub-atualizacao-X.zip`, em **Releases**).
O app de cada pessoa do time procura aqui a versão nova ao abrir, baixa em segundo plano e pergunta antes de instalar.

Usar o app exige conta e convite do time; o código-fonte fica num repositório privado.

Para publicar: envie o zip para `incoming/` (com `incoming/notas-X.md`, opcional). A automação
`Publicar versão` cria a Release `vX` com o zip e limpa a pasta.
